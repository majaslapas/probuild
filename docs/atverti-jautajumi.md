# Atvērtie jautājumi

Jāprecizē ar klientu skeleta tikšanās laikā vai mājasdarbā.

- [ ] **Nomas cena:** rādīt konkrētu cenu vai "pēc vienošanās"?
- [ ] **Komanda:** vai ir ko rādīt (cilvēki, amati, bildes)? Ja nav, bloku izņem no "Par mums".
- [ ] **Partneri / zīmoli:** ar kuriem zīmoliem vai piegādātājiem klients strādā?
- [ ] **Logo:** vai sievas iesāktais logo ir gatavs? Jāredz pirms dizaina.
- [ ] **Bildes:** kādas reālas darbu bildes (īpaši pirms/pēc portfolio) klientam ir?
- [ ] **Pakalpojumu saraksts:** galīgie pakalpojumi; vai iekļaut apsaimniekošanu?
- [ ] **Nomas kategorijas:** vai būs vairākas produktu grupas (piem., būdiņas)?
- [ ] **Sākumlapas fona bilde:** ved uz produktiem vai nomu (izlems izstrādes gaitā).
